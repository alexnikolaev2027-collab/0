# IMEI-помощник

Мобильное приложение: определение модели по TAC и подбор второго IMEI.

## Что должно лежать в репозитории

```
main.py                            ← само приложение
tac_database.db                    ← база моделей из настольной версии
pyproject.toml                     ← настройки сборки и зависимости
.gitignore
.github/workflows/build-apk.yml    ← сборка APK
```

Только эти файлы. Папки `core/` и `ui/` от настольной версии сюда **не нужны** —
вся логика уже внутри `main.py`.

## База моделей

Файл `tac_database.db` берётся из настольной версии **как есть**, ничего
конвертировать не надо. Приложение читает из него таблицы `tac_devices` и
`tac_pairs_lib` и открывает файл только на чтение.

Имя файла должно быть одним из: `tac_database.db`, `tac_base.db`, `tacs.db`.

### Если база больше 100 МБ

GitHub не принимает обычным способом файлы больше 100 МБ. Тогда нужен Git LFS —
один раз на компьютере:

```bash
git lfs install
git lfs track "*.db"
git add .gitattributes tac_database.db
git commit -m "База моделей"
git push
```

Появившийся файл `.gitattributes` тоже добавьте в репозиторий. В workflow
поддержка LFS уже включена.

### Как уменьшить базу

Если размер мешает, лишние столбцы можно выкинуть и сжать файл:

```bash
sqlite3 tac_database.db "VACUUM;"
```

## Сборка

Сборка запускается сама при каждом изменении в репозитории, либо вручную:
вкладка **Actions** → **Собрать APK** → **Run workflow**.

Готовый APK лежит в артефактах завершившейся сборки — блок **Artifacts**
внизу страницы прогона, архив `imei-helper-apk`.

## Проверка после установки

Откройте раздел **Данные** — там написано, подключилась ли встроенная база и
сколько в ней моделей. Если написано «Не найдена», значит файл базы не попал
в репозиторий или назван иначе.

## Запуск на компьютере

```bash
pip install flet
python main.py
```

База должна лежать в той же папке.
